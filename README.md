# 📚 Como o Bruno obteve a mesma nota da Maria 😂

Bem-vindo ao site mais **racional e irreverente** do mundo escolar!  

Aqui você vai acompanhar a épica jornada de:

- **Bruno 😎** – o aluno humilde, racional, que não liga muito para notas, mas sempre dá um jeitinho.  
- **Maria 🤓** – a aluna nota 10, perfeccionista, que não aceita ajuda nem de anjos.  

---

## 📝 Sobre o projeto
Este site é uma **sátira acadêmica**, mostrando como às vezes a vida (e as provas) podem ser **injustamente iguais**.  
Mesmo sem se esforçar tanto quanto a Maria, Bruno conseguiu tirar a mesma nota!  

> “Provas: onde esforço e sorte se encontram de forma cósmica.” 😂

---

## 🎨 Características do site
- HTML5 semântico e CSS moderno  
- Seções coloridas para cada personagem e evento  
- Humor e sátira em cada bloco de texto  
- Box de “Moral da História” com reflexões hilárias  
- Totalmente **responsivo e acessível**
